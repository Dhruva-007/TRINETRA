# TRINETRA Data Contract

## Network State Input

File:

data/windows/network_states_with_delta.csv

Each row represents one 5-second temporal network state.

## Primary Features

- total_connections
- unique_sources
- unique_destinations
- unique_peers
- unique_ports
- bytes
- packets
- connection_rate
- new_peer_rate
- syn_ratio
- rst_ratio
- average_duration
- communication_entropy

## Temporal Features

Each primary feature also has a corresponding delta:

feature_delta = feature(t) - feature(t-1)

## Ordering

Rows are ordered by:

window

The `window` value is an integer temporal index.

## Dynamic Graph Input

Directory:

data/graphs/

Files:

graph_XXXX.json

Each graph represents network topology during one temporal window.

## Graph Nodes

IP addresses.

## Graph Edges

Directed communication:

source_ip -> destination_ip

## Edge Attributes

- packets
- bytes
- protocol

## Node Attributes

- in_degree
- out_degree
- degree

## ML Interface

The ML engine may consume:

1. Network-state sequences
2. Optional temporal-delta sequences
3. Dynamic graph information

The preprocessing layer does not produce anomaly scores,
future-risk scores, or security verdicts.

Those are generated by the ML/security layers.
